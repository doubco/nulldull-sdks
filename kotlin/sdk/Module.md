# Module NullDull Kotlin SDK

Official NullDull SDK for Kotlin and Android (early access, 0.4.0). Read published Grid content
with a public key, and read Memory and export Locale catalogs with a private key.

Start with [com.nulldull.sdk.NullDullClient].

# Package com.nulldull.sdk

The client, its `grid`, `memory` and `locale` namespaces, the response models and
[com.nulldull.sdk.NullDullException].
